# CIF_NI_CIPC
Wrappers around the NI dll for CIPC (circular interprocess communication) library
CIF_CIPC.dll must be installed in the ..\LabVIEW 20xx\resource\ directory
CIF_CIPC.so must be installed in the /usr/lib/x86_64-linux-gnu/ directory
Eventually installers (VIPM for Windows and ipk for RT) will properly install these files
